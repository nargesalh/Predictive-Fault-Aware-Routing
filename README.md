
# Predictive Fault-Aware Routing

A research-oriented project exploring link-failure detection,
failure prediction, and fault-aware routing in simulated networks.

## Research Question

Can predicting link-failure risk help reduce network recovery
time and packet loss compared with reactive routing and
precomputed backup paths?

## Current Status

Milestone 0: Project setup and research scope definition.

No machine-learning model or real-hardware integration has
been implemented yet.

## Planned Roadmap

1. Build a baseline network simulator.
2. Simulate link failures and route recovery.
3. Calculate network reliability and generate scenarios.
4. Develop failure detection and prediction models.
5. Integrate prediction into routing decisions.
6. Evaluate and compare the proposed approach.

## Technology Stack

- Python
- NetworkX
- pytest
- Git and GitHub

## Research Note

The project is an experimental extension inspired by
network reliability research. The proposed method must be
evaluated against established baselines before making
performance claims.
